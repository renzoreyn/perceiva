# Perceiva

Money looks different depending on where you are.

4,700 AMD feels like nothing — pocket change, a coffee, whatever. But that's 170,000 IDR. That's not nothing. That's the problem Perceiva solves.

Perceiva is a personal finance tracker built around one idea: **perception**. When you log a transaction, you don't just see the number you typed. You see what it actually means — converted in real-time, across every currency you use, anchored to a single truth.

---

Built for the person whose salary arrives in two currencies, whose rent is in a third, and whose brain still hasn't fully mapped the exchange rate between them. No mental math. No spreadsheets. Just clarity.
